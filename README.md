# Dream Nation 2026 · Timetable

Timetable du festival Dream Nation (30 et 31 octobre 2026, Paris Nord Villepinte) : les trois scènes de chaque nuit, les sets en cours, les favoris et les styles de chaque artiste.

- Page statique, sans build : `index.html` contient le style, les données et le script.
- Installable sur l'écran d'accueil et consultable hors ligne (`manifest.webmanifest`, `sw.js`).
- Les tags de style viennent uniquement des pages artistes de [dreamnation.fr](https://dreamnation.fr/programmation/).

Pour la lancer en local :

```bash
python3 -m http.server 8000
```
